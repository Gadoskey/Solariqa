# 🤝 Contributing to Solariqa

Thanks for considering contributing! We welcome all kinds of contributions — code, documentation, design, and ideas.

## 📝 Before You Start

Please **open an issue** describing your proposed change (feature, bug fix, enhancement) before starting work. This helps us:
- Avoid duplicate efforts
- Discuss solutions beforehand
- Assign the issue if approved

Use labels like:
- `feature`
- `bug`
- `documentation`


## 🛠 How to Contribute

1. **Fork the repo**
2. **Create a new branch**  
   `git checkout -b feature/your-feature-name`

3. **Make your changes**  
   Follow our coding style and best practices.

4. **Commit with a clear message**  
   `git commit -m "feat: add vote system"`

5. **Push and open a PR**  
   `git push origin feature/your-feature-name`

---

## 📂 Branch Naming

| Type     | Format            |
|----------|-------------------|
| Features | `feature/<name>`  |
| Fixes    | `fix/<bug-name>`  |
| Docs     | `docs/<update>`   |

---

## 🧪 Testing & Review

- All PRs are reviewed manually
- Please add clear screenshots or video of UI changes
- Add tests where relevant

Happy building with us!
